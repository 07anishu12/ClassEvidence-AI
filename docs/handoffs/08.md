## 5. Decisions and rationale

- Audio extraction preserves source timing as explicit metadata because WAV output alone does not safely carry the original video timeline for later evidence references.
- Silence is reported as low amplitude, not automatically as a teaching defect. Brief low-amplitude gaps are only labelled possible dropouts and remain uncertain.
- Clipping is a technical limitation and cannot dominate the pedagogical rubric.
- Transcript providers must return strict bounded segments. The parser rejects out-of-range offsets rather than silently clamping them.
- Speaker IDs are optional opaque labels. The system never infers teacher/child identity and marks all supplied diarization as uncertain.
- The default transcriber is blocked until an organiser-approved local or remote model is configured. No mock transcript is exposed.
